# novel-downloader 项目速览

> 更新日期：2026-10-09 ｜ 用途：一页纸速查卡

## 这是什么

学习用途的**小说下载工作台**：书源驱动 + 并发池 + EPUB 导出。
Node.js 原生零运行时依赖，唯一 devDependency 为 `@yao-pkg/pkg`（打包 `dist/novel-downloader.exe`）。

## 核心模块一览

| 模块 | 职责 |
|---|---|
| `novel-downloader.js` | 核心引擎：目录解析、并发限速抓章、断点续传、TXT/EPUB 导出；CLI + 库双入口 |
| `web-ui.js` | HTTP 服务（UI:8735 / mock:8734），搜索 SSE、书架、任务互斥 |
| `web-ui.html` | 前端单文件，三主题（墨夜/宣纸/竹青），v3 定版 + 两批不可见修复 |
| `legado-adapter.js` / `legado-rules.js` | Legado 书源兼容层（链式选择器 + JSONPath 子集） |
| `source-health.js` | 书源健康度体检（真实搜索探测，连续失败 3 次判死、自愈） |
| `local-import.js` | 本地 TXT/EPUB 导入（切章 + 最小 zip 读取） |
| `mock-novel-site.js` | 本地模拟站夹具：GBK/gzip/瞬时 500/限流 503 四类干扰 |

## 反爬能力（四件套）

`opt.browserLike` 一键启用：

1. 浏览器头套件（Accept / Sec-Fetch-* 等）
2. Cookie 会话罐（按 host 收集）
3. 429/403/503 自适应降速 + host 分桶限速
4. 代理出口（HTTPS_PROXY / HTTP_PROXY + NO_PROXY，支持鉴权）

另有：重试分类（确定性错误不重试）、反爬熔断（连续跨域重定向失败停领新章）。

## 书源现状

- 当前 **9 个真实书源**（6 API 源 + 速读谷 + 就爱文学 + 新笔趣阁），搜索→目录→正文全链路实测通过
- 番茄小说官方 API 无密钥不可用；手动链接模式粘贴 `fanqienovel.com/page/{bookId}` 可下全本
- 用户书源持久化路径：exe 态 = `dist/user-book-sources.json`，dev 态 = 项目根

## 易忘的坑（速记）

- `.main` 翻章回顶三件套缺一不可：`flex:1 1 auto` + `height:calc(100vh-340px)` + `grid-template-rows:minmax(0,1fr)`
- exe 态 outputRoot = **exe 同目录**（`dist/output`），与开发态 `./output` 是两套数据
- exe 运行中文件锁定，重打包输出新文件名（如 `novel-downloader-vXX.exe`）
- 章节文件名 `chapter_NNN.txt`（padStart 3）与既有 manifest 兼容，不可轻改
- 探测结果 Map 必须存布尔值（存 Promise 会全量假活）

## 快速上手

```bash
node web-ui.js          # 启动 UI（默认 8735）
node mock-novel-site.js # 本地模拟站（8734，联调用）
npm run build           # 打包 exe（须 pkg 直调 lib-es5/bin.js）
node test/engine.test.js# 引擎固化用例（legado 语义 3 例）
```
